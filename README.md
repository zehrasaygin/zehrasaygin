- Performed data preprocessing, feature engineering, and model evaluation.
- Developed and compared classification models using Python, Scikit-learn, and XGBoost.
- Achieved **95.67% accuracy** and **95.70% F1-score** with XGBoost.

**🤖 Local RAG Assistant**

A privacy-oriented local AI assistant developed to answer questions about documents using locally deployed language models.

- Used Microsoft Foundry Local SDK and Qwen2.5-0.5B.
- Explored Retrieval-Augmented Generation (RAG) and local LLM inference.
- Focused on privacy-oriented and resource-efficient AI applications.

**🎬 Movie Ticket Management System**

A full-stack movie ticket management application developed with React, Node.js, Express.js, and MongoDB.

- Designed and implemented 15+ RESTful API routes.
- Developed backend services for movies, showtimes, bookings, users, and favourites.
- Worked with MongoDB Atlas, Mongoose, and backend integration.

**🚗 Animated Wireframe Car**

An interactive 3D wireframe vehicle developed using C++, OpenGL, and GLUT.

- Implemented hierarchical modelling and geometric transformations.
- Added real-time movement, steering, multiple camera views, lighting, and fog effects.
